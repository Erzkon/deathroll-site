Deathroll – Party Dice

Le duel de dés rapide pour les fêtes et les soirées jeux. Un iPhone passe de main en main, et qui fait 1 perd.

Télécharger dans l’App Store

Ce que l’app sait faire

  • Classique : lancez chacun votre tour pendant que la limite rétrécit ; qui fait 1 perd.
  • Élimination : qui fait 1 est éliminé. On continue jusqu’à ce qu’il n’en reste qu’un.
  • Statistiques : chaque partie compte automatiquement : classement, la poisse et votre face-à-face.
  • Chacun sur son iPhone : à proximité par Wi-Fi ou Bluetooth, en ligne avec un code de table via Game Center, et les amis sans l’app (par ex. sur Android) jouent dans le navigateur grâce à un QR code.
  • Succès : 25 succès pour les moments forts autour de la table, dont quelques-uns secrets.
  • Qui commence ? Deathroll tire au sort l’ordre de jeu pour vos jeux de société et plus encore.

Comment jouer

Le premier joueur lance entre 1 et le nombre de départ, par exemple 1 000. Le résultat devient la nouvelle limite pour le joueur suivant : ça se resserre à chaque lancer. Qui fait 1 perd.

FAQ

Comment couper le son ?

Dans l’app, ouvre Réglages (roue dentée sur l’écran d’accueil) → « Son ». Deathroll suit aussi le mode silencieux de l’iPhone.

Comment couper les vibrations ?

Dans l’app, ouvre Réglages → « Vibrations ».

L’app est-elle payante ?

Non. Deathroll est gratuite, sans pub ni achats intégrés.

Joue-t-on avec de l’argent réel ?

Non. Deathroll est un jeu d’ambiance. Il n’y a ni paris d’argent ni gains. Le « gage » n’est qu’une ligne de texte que vous inventez, comme qui fait la vaisselle.

Des amis sur Android peuvent-ils jouer ?

Oui. Celui qui ouvre la table active « Autoriser les joueurs via navigateur » dans le lobby. Les autres scannent le QR code et jouent dans le navigateur, sans app, sur le même Wi-Fi ou via le partage de connexion de l’iPhone hôte.

Faut-il Internet ?

Pas pour « À proximité » : les iPhone se connectent directement par Wi-Fi ou Bluetooth, les joueurs via navigateur par le Wi-Fi local ou le partage de connexion. Pour « En ligne » avec un code de table, oui : chaque iPhone a besoin d’Internet et doit être connecté à Game Center.

Quelles données l’app collecte-t-elle ?

Aucune. Les noms, l’historique, les statistiques, les succès et les réglages restent sur ton iPhone. Plus de détails dans la politique de confidentialité (en anglais).
